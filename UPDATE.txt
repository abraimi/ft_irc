I built the basic networking foundation of the IRC server. The server creates a non-blocking TCP socket, configures it, binds it to the chosen port, and listens for incoming connections. I then implemented a poll() loop that monitors the server socket and all connected clients. The server can now accept multiple clients, add their sockets to poll(), receive data with recv(), and detect/remove disconnected clients.

How to Compile
make

Then start the server with:

./ircserv 6667 password
How to Test

In another terminal, connect with:

nc 127.0.0.1 6667

Type something:

hello

The server should display:

New client connected: fd 4
Client 4 sent: hello

Open another terminal and connect again:

nc 127.0.0.1 6667

You should get another client FD, for example:

New client connected: fd 5
Client 5 sent: bonjour

You can also close one nc connection and the server should detect the disconnection and remove its FD from poll().
